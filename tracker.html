策略引擎分析（新版）

基于三套独立规则的薄弱点判定 + 行为指标计算 + 改进建议

判定规则说明
规则1：通过率策略 (Pass Rate)
公式: 通过率 = 该标签下AC的题目数 / 尝试过的题目总数
支持难度加权（基础题错误扣分更重）。阈值 α = 0.3，通过率 < 30% 判定为薄弱。
通过率为 0 的标签（从未 AC）不参与薄弱判定，单独归为"尚未掌握"。
规则2：时间与效率策略 (Efficiency)
条件A: 该标签平均尝试次数 > γ（γ = 3 次）
条件B: 该标签平均解题耗时 > β × 全站同类题目耗时中位数（β = 1.5）
满足任一条件即判定为效率低下（薄弱）。
规则3：学习趋势策略 (Learning Trend)
将历史提交按时间均分为前后半区，计算 后半区正确率 / 前半区正确率
比值 < 0.8（后期显著下降）或 周正确率线性回归斜率 < 0.05（几乎无进步），判定为薄弱。
